# Como contribuir

Obrigado pelo interesse em contribuir com o **meu-terceiro-repo**!

1. Faça um fork do repositório e crie uma branch a partir da `main`.
2. Faça commits pequenos, com mensagens claras.
3. Abra um Pull Request descrevendo o que mudou e por quê.

Dúvidas ou sugestões? Abra uma issue.
